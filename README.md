# MSD LAW — Independent Website Redesign Preview
A responsive, premium website concept published separately from the original law firm website.

The site **is not the law firm's official site** and includes no verified firm-specific biographies, credentials, case results, testimonials or contact details.

## Features
Responsive luxury design, six example practice modules, prospective attorney sections, intake demonstration, FAQ, browser-only rule-based guide, accessible menu, descriptive image text, reduced-motion support, favicon.

## Publishing
Set Settings → Pages → Source to **GitHub Actions**. A workflow deploys main on every push. The expected URL is https://lawupdates.github.io/msd-law-redesign-preview/

## Important limitations
- The user-provided msdforlaw.com domain has not been reliably verified as the firm.
- Stock photography is illustrative and externally loaded.
- Practice areas are examples pending identification and approval.
- Intake demo does not transmit any information.
- Guided chat is not generative AI, an attorney, or legal advice.
- Meta robots=noindex keeps this unapproved preview out of search indices.
- Replace placeholders and review lawyer advertising, accessibility, privacy, and image licensing before official launch.

## Before a professional production launch
1. Obtain the firm's explicit written approval and verify biographies, practice jurisdiction, attorney credentials, service offerings, contact details, and legal claims.
2. Audit every page for accessibility, mobile performance, SEO metadata, broken links, cross-browser behavior, imagery permissions, privacy requirements, and relevant attorney advertising rules.
3. Replace the demonstration intake with an approved encrypted CRM workflow and consent/privacy disclosures. Do not ask visitors to submit confidential facts before conflicts screening.
4. For genuine generative AI, use an authenticated server-side API proxy (never expose provider keys in browser code); restrict answers to attorney-approved site content; add moderation, citations or source links, escalation to humans, rate limits, abuse handling, minimal retention, telemetry without client secrets, and legal-specific guardrails. Do not claim attorney–client relationship or give case-specific legal advice.
5. Test the deployed site and configure a production domain only after ownership authorization. The independent GitHub preview must not impersonate the firm.
