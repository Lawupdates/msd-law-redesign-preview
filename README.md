# MSD LAW — Independent Website Redesign Preview
A responsive, premium website concept published separately from the original law firm website.

The site **is not the law firm's official site** and includes no verified firm-specific biographies, credentials, case results, testimonials or contact details.

## Features
Responsive luxury design, six example practice modules, prospective attorney sections, intake demonstration, FAQ, browser-only rule-based guide, accessible menu, descriptive image text, reduced-motion support, favicon.

## Publishing
Set Settings → Pages → Source to **GitHub Actions**. A workflow deploys main on every push. The expected URL is https://lawupdates.github.io/msd-law-redesign-preview/

## Important limitations
- The user-provided msdforlaw.com domain has not been reliably verified as the firm.
- Stock photography is illustrative and externally loaded.
- Practice areas are examples pending identification and approval.
- Intake demo does not transmit any information.
- Guided chat is not generative AI, an attorney, or legal advice.
- Meta robots=noindex keeps this unapproved preview out of search indices.
- Replace placeholders and review lawyer advertising, accessibility, privacy, and image licensing before official launch.


## Expanded pages (October 2026)

Added 11 standalone responsive pages covering firm, attorney, practice areas, motor vehicle accidents, no-fault/PIP, medical malpractice, civil rights, FAQs, insights, contact, and privacy. Home navigation links to the expanded pages. All content remains a separate design preview with no client intake backend.
